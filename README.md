# Python Basic Programs

This repository contains **30 beginner-friendly Python programs** that demonstrate the use of:
- Conditional statements (`if`, `elif`, `else`)
- Logical operators
- `match-case` (Python’s version of switch-case)
- Input/Output handling

These programs are designed as practice exercises for anyone learning Python basics.

## ✨ Features
- **Interactive Input**: All programs use `input()` for user values.  
- **Decision-Making Practice**: Covers multiple ways to handle conditions — simple `if-else`, nested `if`, and `match-case`.  
- **Error Handling Examples**: Includes default cases (e.g., invalid day/month).  
- **Real-Life Scenarios**: Practical examples like voting eligibility, discount calculation, income tax, and login validation.  
- **Beginner-Friendly**: Clear structure, easy to understand, and ideal for practice or teaching.
